## 1. Test Objectives

### Primary Objectives
1. Verify all backend APIs function correctly
2. Validate authentication and authorization
3. Test complete loan application workflow
4. Verify audit logging accuracy
5. Validate business rules and calculations
6. Test role-based access control

### Success Criteria
- All critical APIs return expected responses
- Authentication flow works for all roles
- Audit logs capture all actions
- Business calculations are accurate
- No critical bugs blocking demo

## 3. Test Phases

### Phase 1: Backend API Testing (2 hours)

#### 1.1 Authentication APIs
**Tool:** Postman/curl  
**Base URL:** `http://localhost:5000/api`

**Test Cases:**

```bash
# TC-API-001: Login with valid credentials
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"rm1","password":"password123"}'

Expected: 200 OK, returns user object and JWT token

# TC-API-002: Login with invalid credentials
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"rm1","password":"wrong"}'

Expected: 401 Unauthorized, error message

# TC-API-003: Get current user
curl -X GET http://localhost:5000/api/auth/me \
  -H "Authorization: Bearer {token}"

Expected: 200 OK, returns user object

# TC-API-004: Access protected route without token
curl -X GET http://localhost:5000/api/applications

Expected: 401 Unauthorized
```

#### 1.2 Applications APIs

```bash
# TC-API-005: Get all applications
curl -X GET http://localhost:5000/api/applications \
  -H "Authorization: Bearer {token}"

Expected: 200 OK, returns array of applications

# TC-API-006: Get application by ID
curl -X GET http://localhost:5000/api/applications/APP-2024-001 \
  -H "Authorization: Bearer {token}"

Expected: 200 OK, returns application object

# TC-API-007: Create new application (RM only)
curl -X POST http://localhost:5000/api/applications \
  -H "Authorization: Bearer {rm_token}" \
  -H "Content-Type: application/json" \
  -d '{
    "applicant_name": "Test Company Inc",
    "business_type": "Corporation",
    "industry": "Retail",
    "years_in_business": 5,
    "loan_amount": 100000,
    "tenor_months": 12,
    "loan_purpose": "Working Capital",
    "repayment_type": "Monthly",
    "monthly_revenue": 50000,
    "monthly_expenses": 30000,
    "existing_debt_payment": 5000,
    "collateral_type": "Real Estate",
    "collateral_value": 150000,
    "owner_name": "John Doe",
    "owner_id": "123456789",
    "credit_score": 700
  }'

Expected: 201 Created, returns new application

# TC-API-008: Update application (Draft only)
curl -X PUT http://localhost:5000/api/applications/{id} \
  -H "Authorization: Bearer {rm_token}" \
  -H "Content-Type: application/json" \
  -d '{"loan_amount": 120000}'

Expected: 200 OK, returns updated application

# TC-API-009: Submit application
curl -X POST http://localhost:5000/api/applications/{id}/submit \
  -H "Authorization: Bearer {rm_token}"

Expected: 200 OK, status changes to "Submitted"

# TC-API-010: Delete application (Draft only)
curl -X DELETE http://localhost:5000/api/applications/{id} \
  -H "Authorization: Bearer {rm_token}"

Expected: 200 OK, application deleted
```

#### 1.3 Agent Review API

```bash
# TC-API-011: Run agent review
curl -X POST http://localhost:5000/api/applications/{id}/agent-review \
  -H "Authorization: Bearer {token}"

Expected: 200 OK, returns review results with:
- extracted_fields
- missing_documents
- data_quality_warnings
- risk_flags
- recommended_decision
- recommended_conditions
```

#### 1.4 Analysis API

```bash
# TC-API-012: Get analysis
curl -X GET http://localhost:5000/api/applications/{id}/analysis \
  -H "Authorization: Bearer {token}"

Expected: 200 OK, returns analysis with DSCR, cashflow, etc.

# TC-API-013: Create analysis
curl -X POST http://localhost:5000/api/applications/{id}/analysis \
  -H "Authorization: Bearer {analyst_token}"

Expected: 201 Created, returns new analysis
```

#### 1.5 Decision API

```bash
# TC-API-014: Submit recommendation (Analyst)
curl -X POST http://localhost:5000/api/applications/{id}/decision \
  -H "Authorization: Bearer {analyst_token}" \
  -H "Content-Type: application/json" \
  -d '{
    "recommended_decision": "Approve",
    "notes": "Strong financials"
  }'

Expected: 201 Created, returns decision

# TC-API-015: Finalize decision (Approver)
curl -X PUT http://localhost:5000/api/applications/{id}/decision \
  -H "Authorization: Bearer {approver_token}" \
  -H "Content-Type: application/json" \
  -d '{
    "final_decision": "Approved",
    "conditions": ["Provide additional collateral"],
    "reason": "Approved with conditions"
  }'

Expected: 200 OK, returns finalized decision
```

#### 1.6 Memo API

```bash
# TC-API-016: Generate credit memo
curl -X GET http://localhost:5000/api/applications/{id}/memo \
  -H "Authorization: Bearer {token}"

Expected: 200 OK, returns HTML memo
```

#### 1.7 Audit API


#### 1.8 Config API

```bash

  -H "Authorization: Bearer {token}"

  -H "Authorization: Bearer {admin_token}" \
  -H "Content-Type: application/json" \

Expected: 200 OK, returns updated policy
```

## 5. Defect Reporting

### Defect Template

```markdown
**Defect ID:** DEF-XXX
**Severity:** Critical/High/Medium/Low
**Priority:** P1/P2/P3/P4
**Status:** Open/In Progress/Fixed/Closed

**Summary:** Brief description

**Steps to Reproduce:**
1. Step 1
2. Step 2
3. Step 3

**Expected Result:** What should happen

**Actual Result:** What actually happened

**Environment:**
- Browser: Chrome 120
- OS: macOS 14
- Backend: v1.0.0
- Frontend: v1.0.0

**Screenshots:** [Attach if applicable]

**Logs:** [Attach console logs if applicable]
```

### Severity Definitions

- **Critical:** Blocks core functionality, no workaround
- **High:** Major feature broken, workaround exists
- **Medium:** Minor feature issue, doesn't block workflow
- **Low:** Cosmetic issue, doesn't affect functionality
